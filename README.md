# 白虎面板：脚本

觉得青龙面板有些臃肿后的轻量替代方案，核心功能完备，系统资源占用更低。本仓库提供适用于[白虎面板](https://github.com/)的自动化定时任务脚本。

## 导入仓库

1. 进入面板：点击左侧导航 **定时任务** -> 页面左上方 **仓库**。
2. 添加仓库并配置如下：
   - **源地址**：本仓库 Git 地址
   - **文件后缀**：`py`
   - **语言环境**：`python`
   - **自动添加任务并解析元数据**：勾选
3. 保存后执行拉取，白虎面板将自动根据各脚本开头的元数据添加定时任务。

## 列表

默认都是需要配置环境变量才能使用，如何配置请看具体的脚本。

- [B站动态](src/bilibili_dynamic.py)：监控关注的 UP 主动态/新视频推送
- [雪球基金](src/danjuan_funds.py)：每日净值更新、持有收益与收益率计算提醒
- [Trakt](src/trakt.py)：剧集/新番进度更新提醒
- [轻小说文库](src/wenku8.py)：轻小说最新章节更新提醒
- [爱丽丝书屋](src/alicesw.py)：小说最新章节更新提醒
